# Bio-COMSOL

Ионный транспорт на графах: модель Нернста-Планка-Пуассона для синтетических ионных систем и биологической ткани.

Validated against analytical solutions for Nernst equilibrium, 1D diffusion (first-order convergence), Boltzmann distribution, and 2D Poisson symmetry.

## CI

Полный прогон: **211 passed** (GitHub Actions, ~13 минут).

## Что это

Модульная система для моделирования:

- Ионного транспорта в электролитах и биологических тканях
- Мембранных потенциалов через уравнение Пуассона
- Нейронов Ходжкина-Хаксли с динамическим Нернстом
- Синапсов и сетей с обучением через STDP
- Самосогласованного потенциала — phi зависит от концентраций
- Транспорта по схеме Шарфеттера-Гуммеля (положительность при Pe > 2)

## Физика

### Ионный транспорт (Нернст-Планк-Пуассон)

Поток Нернста-Планка:

    J_i = -D_i * grad(c_i) - (D_i * z_i * F / RT) * c_i * grad(phi)

Уравнение Пуассона:

    laplacian(phi) = -(F / eps) * sum(z_i * c_i)

Схемы:

- **Пикар** — линейная сходимость, до 20 итераций
- **Ньютон** — квадратичная сходимость, 1–2 итерации (аналитический якобиан)
- **SG (Шарфеттер-Гуммель)** — положительность концентраций при любом dt и Pe > 2

### Границы из атрибутов графа (v0.9.0+)

Дирихле-граница ставится в произвольный узел через атрибуты графа
(`node_type`, `phi_boundary`, `c_boundary`); солвер слеп к геометрии —
1D-цепочка и 2D-сетка работают на одном ядре. Чтение атрибутов защищено
(v0.9.3): нестроковые значения `node_type` и не-dict спеки `c_boundary`
не рушат конструктор, пустая разметка даёт честный фолбэк на легаси-узлы.

### Sparse-Ньютон (v0.9.2)

Сборка якобиана в CSR без tolil-преобразований в горячем цикле:
`J_k = A_mats[k] + dt * (S_mask @ adv_jac)`. Замер на сетке 50x50,
4 иона: сборка якобиана ускорена **x27** (177 -> 6.6 мс/шаг), полный шаг —
**131 мс**. Ориентир для глии ~40 000 узлов: 8–9 с/шаг на прямых сплайвах —
дальше нужен итерационный солвер. Также исправлено отставание phi на итерацию
в самосогласованном режиме.

### Нейрон Ходжкина-Хаксли

    C_m * dV/dt = I_ext - I_Na - I_K - I_L

С динамическими равновесными потенциалами Нернста:

    E_i = (RT / z_i F) * ln(c_i_out / c_i_in)

Защита от overflow: `np.clip(V, -100, 100)` перед экспонентами.

### Синапсы и STDP

Проводимостная модель с детекцией спайков и обучением:

- LTP — pre до post, вес растёт
- LTD — post до pre, вес падает
- Клиппинг весов, экспоненциальное затухание

### Контракт единиц (units.py)

Все внутренние расчёты — строго в СИ (В, м, с, К); внешние входы/выходы —
в биологических единицах (мВ, мкм, мс). Константы RT/F и F/RT вычисляются
из CODATA (не зашиты числом); санити-замки: наклон Нернста при 37 C =
26.7267 мВ, E_K при 5/140 = -89.06 мВ. Обратное преобразование мВ -> В -> мВ
не бит-в-бит (~1e-14 мВ на ~13% значений) — оговорка защищена замком
`test_roundtrip_not_bitexact_documented`.

## Валидация

| Тест | Аналитика | Допуск |
|---|---|---|
| Нернст | E = (RT/zF) * ln(c_out/c_in) | rtol < 1e-3 |
| 1D-диффузия | c0/2 * [1 - erf(x / 2*sqrt(Dt))] | max err < 1e-2 |
| Порядок сходимости | ошибка ~ dt | ratio 1.7..2.3 |
| Больцман | c ~ exp(-z*phi/kT) | R2 > 0.99 |
| Симметрия Пуассона (2D) | поле симметрично по сетке | ~1e-15 |
| Линейное поле (2D) | laplacian(phi) = 0 на сетке | err < 3.9e-16 |
| SG-позитивность | c >= 0 при Pe > 2, любой dt | строгая |
| Sparse == legacy | sparse-Ньютон vs tolil-Ньютон | diff < 1e-12 |

## Запуск

```
pip install numpy scipy pyyaml pytest
```

Полная симуляция из конфига:

```
python main.py
```

С CLI-параметрами:

```
python main.py --steps 1000 --dt 1e-4
```

Тесты:

```
python -m pytest tests/ -v
```

Только валидация:

```
python -m pytest tests/test_validation.py -v
```

## Конфигурация

Всё в `config.yaml`:

```yaml
graph:
  N: 50
  topology: chain
  conductivity: 1.0
  cross_section: 1e-8

ions:
  - {name: Na,  D: 0.01,  z: 1,  c0: 10.0}
  - {name: K,   D: 0.02,  z: 1,  c0: 100.0}
  - {name: Cl,  D: 0.015, z: -1, c0: 110.0}
  - {name: Ca,  D: 0.008, z: 2,  c0: 1.0}

solver:
  method: newton
  self_consistent: true
  dt: 1e-4

neuron:
  enabled: true
  indices: [20, 25, 30]

synapse:
  enabled: true
  stdp: true
```
